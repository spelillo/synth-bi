# synth-bi

## Synth-bi is the newest iteration of data tools, building off of synth-sql. (www.synth-sql.com).
- Synth-sql works by having users seamlessly upload CSV files, then run SQL queries against them right in the browser. No db setup in the cloud.
- Synth-sql also has an ai assistant, that has 2 modes: 1. Sql 2. General. SQL mode for AI allows the user to ask plain-english questions to help write quereis, and the AI reads the prompt, and leveraging the current csv(s) in the session, outputs a query to run. General mode is for more non-sql output questions, like asking about schema, PK/FK relationships, and other DB questions.

## Synth-bi scope
- Synth-bi will be similar to synth-sql, as it will allow simple upload of csv/json files, except now excel too. The point of this is to, like synth-sql, allow the user to leverage AI and simple querying, along with a baked in visual preview type, similar to how the user in sql can interact with a sql query box and see query outputs.
