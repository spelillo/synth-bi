How Synth-BI works

Your data stays in this tab

Every file loads into a SQLite database running inside this browser tab. Nothing is sent anywhere unless you sign in and choose to save or use the AI assistant. Even then, the assistant only ever sees column names and types, never your rows.

Tables

Each CSV or JSON file becomes one table; each sheet of an Excel workbook becomes its own table. Click a table chip to browse it in Table View, or the pencil to rename it (tiles that use it follow the rename). Add table adds more files to this dashboard; choosing a new file from the home page starts a fresh one.

Building tiles

Add tile opens the tile editor. Visual mode builds the query for you from a table, a group-by column, and a measure, and the SQL it writes is always shown underneath. SQL mode lets you write the query yourself. Either way, pick a chart type and add it to the dashboard. Drag a tile by its title bar to move it, and from its corner to resize it.

Relationships

With two or more tables, the Relationships tab suggests how they connect (like orders.customer_id → customers.id). Confirm the real ones; the AI assistant uses them as join hints.

Lite vs. Normal Mode

Without an account, everything above works. A free account adds the AI assistant, saving dashboards across devices, and exporting to Power BI or Tableau.
